Архив и ранее распакованная папка совпали по SHA-256 для всех 66 файлов.

Проверены генератор, JS, CSS, документация, 50 HTML-страниц и характеристики 5 MP4.

## Причина невидимых видео

Пути существовали и уже использовали ASCII. ffprobe показал H.264/yuv420p во всех
пяти MP4: hero 1280×720, мастер 1080×1080, три макровидео 400×500.
В браузере исходные ролики имели readyState=4 без MediaError.
Ошибка — img и video друг под другом в обычном потоке внутри контейнера с
overflow:hidden. У четырёх видео пересечение с контейнером было 0 px;
у hero около 10.6 px из-за CSS scale. Это подтверждённая причина невидимости.

Исправлены слои постера и видео; сохранена высота кадра. Активный src появляется
около экрана, preload=none. Главное видео загружается первым; вторичные — при
прокрутке. Вне экрана и при скрытии вкладки воспроизведение останавливается.
Muted, playsinline, poster сохранены. Добавлена кнопка play/pause.
Reduced motion и Save-Data отключают автоматический запуск, сохраняя ручной.
При реальной ошибке остаётся постер. Исходные MP4 не перекодировались.

## Старый сайт: проверенные факты

Источник: https://remontiryemchasi.ru/sitemap_index.xml и шесть вложенных sitemap.
В sitemap найдено 26 HTML URL; все вернули HTTP 200 при обходе.
legacy-pages.csv содержит status, title, description, H1, canonical и robots.
legacy-content.json дополнительно содержит текст, H2/H3, ссылки и время проверки.
Это снимок публичного сайта; фактическая индексация и поисковый трафик не проверены.

- У 23 из 26 страниц нет meta description.
- У /uslugi/remont-shvejczarskih-chasov/ не найден H1 в полученном HTML.
- Canonical присутствует на всех 26 страницах.
- В sitemap есть архив автора, «Без рубрики» и категория с H1 «—».
- /stat/ и /kak-chasto-nuzhno-obsluzhivat-chasy/ имеют одинаковый H1. Объединение требует проверки содержимого и поисковых данных.
- На /kontakty/ шапка сообщает «Ежедневно с 10:00 до 20:00», контактный блок и футер — «Пн-Пт: 10:00–19:30; Сб-Вс: 11:00–18:30». Правильный вариант не выбран.
- На /brands/ перечислены Rolex, Omega, Patek Philippe, Hublot, Cartier, Breguet, Audemars Piguet, IWC, Longines, Tissot. Это упоминание на исходном сайте, а не независимая проверка возможностей мастерской. Остальные 21 марки — pending.
- В HTML шести /raboty/ найдены названия и даты, но не найдены подробные перечни операций и измерений. Эти данные не выдумывались.
- Найденные внутренние ссылки /polity/ и /privacy-policy/ возвращают 404.
- HTTP ведёт на HTTPS; www ведёт на основной домен. Результаты дополнительных запросов — legacy-extra-http.json.

## SEO проекта и миграция

Исходные 50 страниц: главная, 6 разделов, 8 услуг, 31 бренд, 4 кейса.
У всех было по одному H1, но отсутствовали canonical, robots, Twitter metadata,
JSON-LD, favicon и sitemap. Брендовые страницы отличались преимущественно названием;
контакты, прайс и кейсы содержали TODO.

Добавлены canonical, OG URL, Twitter metadata, WebPage JSON-LD, favicon, robots
и генератор sitemap. Все страницы имеют noindex,follow в режиме preview.
Утверждённых индексируемых URL пока нет; sitemap пуст. Контакты со старого сайта
сохранены в config как наблюдения для подтверждения. Противоречивый график не
опубликован как установленный факт.

redirect-plan.csv содержит 26 строк OLD → PROPOSED NEW → STATUS.
301 — предложения для будущего переноса. Для страниц без равноценного содержимого
предлагается сохранить старый URL. Пустой раздел не основание для редиректа
содержательной страницы. На сервере старого сайта ничего не менялось.
