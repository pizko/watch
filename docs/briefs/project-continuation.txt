# КРИТИЧЕСКИЙ КОСЯК ТЕКУЩЕЙ ВЕРСИИ — ИЗОБРАЖЕНИЯ

Мне НЕ нравится, что сейчас на сайте постоянно повторяются одни и те же картинки.

Одна фотография часов может встречаться в hero, услуге, бренде, кейсе и еще нескольких секциях.

Так делать нельзя.

Нужно провести asset audit.

Составь список:

IMAGE → WHERE USED

и найди чрезмерные повторы.

Дальше переработай визуальный контент.

Мне нужно ощущение настоящего большого luxury-сайта, а не шаблона, который построили из пяти фотографий.

Для разных типов контента должны использоваться разные изображения:

### HERO
macro movement / cinematic mechanism

### SERVICES
свои изображения:
- механизм;
- полировка;
- стекло;
- корпус;
- водозащита;
- браслет;
- хронограф;
- реставрация.

### ATELIER
- рабочий стол;
- инструменты;
- мастер;
- микроскоп;
- детали мастерской.

### CASES
каждый кейс должен иметь собственное визуальное оформление.

### BRANDS
не нужно тупо использовать одну фотографию механизма на 20 страницах брендов.

Если уникального изображения нет — лучше использовать типографическую композицию / generative background / macro crop, чем повторять одну и ту же картинку.

Использовать изображения только легально допустимым способом.

Не воровать изображения с Alter Geneva / De Bethune.

# SEO — ЭТО ОЧЕНЬ ВАЖНО

Сайт должен быть не только красивым.

Мне нужен ОЧЕНЬ СИЛЬНЫЙ SEO-фундамент под Google и Яндекс.

Но не надо делать SEO-говносайт с километрами текста.

Нужно соединить luxury UX + нормальное programmatic/content SEO.

## Сначала проведи аудит старого сайта remontiryemchasi.ru

Найди существующие:

- URL;
- услуги;
- брендовые страницы;
- страницы кейсов;
- категории;
- title;
- description;
- H1;
- тексты;
- FAQ;
- внутреннюю перелинковку.

Если старый URL имеет поисковую ценность, его желательно СОХРАНИТЬ.

Если URL меняется — подготовить карту:

OLD URL → NEW URL → 301

Нельзя просто снести индексируемую структуру.

- FAQ именно по бренду;
- ссылки на связанные услуги.

Если уникального контента пока нет — страницу лучше подготовить технически, но не плодить индексируемый thin content.

# PERFORMANCE

Это сайт с большим количеством тяжелого media, поэтому особенно важно.

Видео:

- не грузить все 5 сразу;
- hero preload разумно;
- остальные lazy load / load near viewport;
- poster;
- mobile optimization;
- respects prefers-reduced-motion.

Изображения:

- WebP/AVIF где возможно;
- srcset;
- sizes;
- lazy-loading;
- width/height;
- не грузить 3000px картинку в 400px контейнер.

Стараться сохранить luxury-анимации без убийства LCP/CLS/INP.
