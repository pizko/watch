Развитие существующего статического сайта из `watch-atelier.zip`.
Исходные 66 файлов импортированы без изменений в коммите `2244368`.
Репозиторий: https://github.com/pizko/watch — private.

## Локальный запуск

Python 3.10+; для проверки JavaScript — Node.js.

```sh
python3 build_site.py
python3 tools/verify.py
node --check assets/js/main.js
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8080/ в браузере. На Mac также доступен `start.command`.
Проверять через HTTP, а не через `file://`.

## Где редактировать

- `build_site.py` — шаблоны и исходный контент. HTML генерируется этим файлом.
- `assets/css/styles.css`, `assets/js/main.js` — все стили и исполняемый JavaScript; в HTML нет встроенных CSS и обработчиков. JS подключается с defer.
- JSON-LD остаётся внутри HTML каждой страницы: сейчас это базовый тип WebPage, а не исполняемый скрипт.
- `data/site.json` — режим индексации, будущий домен и контакты для подтверждения.
- `data/brands.json` — марки с источником; неподтверждённые имеют `pending`.
- `docs/briefs/` — оба приложенных текста, сохранённые без изменений.
- `docs/audit/REPORT.md` — результаты первого этапа и ограничения.
- `docs/audit/redirect-plan.csv` — предложения по переносу, не активные редиректы.

## Текущий статус

50 страниц, 5 исходных MP4, существующий проект и структура сохранены.
У видео исправлено положение относительно постера, реализованы загрузка около
экрана, остановка вне экрана, ручное управление и учёт reduced motion / Save-Data.
При ограничениях autoplay остаются постер и кнопка воспроизведения.

Макрокадры больше не используются как фотографии конкретных брендов и ремонтов.
AI-видео обозначены как иллюстративные. Реальные фотографии кейсов ещё нужны.

Это прототип. Все страницы имеют `noindex,follow`; sitemap.xml пока пуст,
поскольку нет одобренных для индексации страниц. Перед публикацией нужно
подтвердить данные, перенести содержимое старых URL, подключить форму и настроить
сервер. Не разворачивать preview поверх remontiryemchasi.ru без проверки миграции.

Обновить локальный аудит: `python3 tools/audit.py after`.
Повторить read-only обход старого сайта: `python3 tools/crawl_legacy.py`.
